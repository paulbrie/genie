# GENIE

This app is a platform that will enable technical and non-technical users to create applications with AI at scale.

## Projects
A project is defining a setup of servers and a configurations of agents that work together to develop the app.

In the projects module we can CRUD projects, set a working folder and launch them by defining one or more bash commands. 

## Running in Cloud
Genie projects shour run in Railway. If the project has docker compose file we should have a process that will enable me to start the project there, not locally.
